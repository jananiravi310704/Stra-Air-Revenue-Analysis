# Stra-Air-Revenue-Analysis
Star Air Data Engineering Project – End-to-end Airline Data Warehouse solution using Snowflake, dbt, and Power BI for revenue analytics, route profitability, financial reconciliation, agent performance, and operational reporting.
✈️ Star Air Data Engineering & Analytics Project

This project simulates a real-world airline data platform designed for Star Air. The solution transforms raw airline operational and financial data into a centralized data warehouse using Snowflake and dbt, enabling business users to analyze revenue, route profitability, load factors, agent performance, and financial reconciliation through Power BI dashboards.
